# AnarchyOps 0.2.0

Meteor Client addon for Minecraft 1.21.11 focused on safety, navigation, supplies and long anarchy sessions.

## Modules

- Threat Radar
- Auto Escape
- Void Guard
- Elytra Guard
- Supply Guard
- Durability Guard
- Rocket Restock
- Panic Pearl
- Marker ESP

## HUD

- Ops Session
- Threat Radar
- Navigation Target

## Commands

```text
.ops status
.ops reset-session
.ops coords nether
.ops coords overworld
.ops mark add <name>
.ops mark remove <name>
.ops mark target <name>
.ops mark clear-target
.ops mark nearest
.ops mark list
.ops snapshot save <name>
.ops snapshot show <name>
.ops snapshot compare <name>
.ops snapshot remove <name>
.ops snapshot list
```
